# DETRAN-SP Quest

Curso gamificado de preparação para o concurso de Agente Estadual de Trânsito do DETRAN-SP 2026.

## Conteúdo
- Trilhas por disciplina
- Aulas com material didático
- Revisões espaçadas
- Exercícios objetivos e dissertativos
- 5 simulados completos
- Pontuação ponderada conforme edital
- Gamificação com XP, níveis e progresso

## Deploy
Projeto estático. O arquivo principal é `index.html`.

No Render, publique a raiz do repositório (`./`) como Static Site.
